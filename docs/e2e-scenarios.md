# E2E Automation Scenarios
> Все сценарии автоматизированы с помощью Playwright. 
> Тесты независимы: каждый создаёт свои данные и удаляет после себя. 

## Администратор

### Аутентификация
- Админ логинится с корректными данными. Ожидаемый результат: редирект на админ-панель.
- Админ вводит неверный пароль. Ожидаемый результат: ошибка, остаётся на /login.

### Управление фото
- Админ загружает фото с файлом, title, author, category, subcategory. Ожидаемый результат: фото появляется в галерее в установленной категории и подкатегории.
- Админ загружает фото без обязательного поля (title / author / файл). Ожидаемый результат: ошибка, фото не загружается.
- Админ удаляет фото. Ожидаемый результат: фото исчезает из галереи.

### Управление категориями
- Админ создаёт категорию и подкатегорию. Ожидаемый результат: категория и подкатегория появляются в сайдбаре. 
- Админ удаляет пустую категорию. Ожидаемый результат: категория исчезает из сайдбара.
- Админ удаляет категорию с фото. Ожидаемый результат: ошибка, категория не удаляется, фото остаются.

### Управление комментариями (полный цикл)
- Админ открывает список всех комментариев. Ожидаемый результат: видит комментарии со статусами PENDING, APPROVED, REJECTED.
- Админ открывает список PENDING комментариев. Ожидаемый результат: видит только комментарии на модерации.
- Админ одобряет комментарий. Ожидаемый результат: комментарий становится виден в галерее, статистика обновляется.
- Админ отклоняет комментарий. Ожидаемый результат: комментарий остаётся скрытым, статистика обновляется.
- Админ удаляет комментарий. Ожидаемый результат: комментарий исчезает из системы.

## Пользователь

### Галерея
- Пользователь открывает главную страницу. Ожидаемый результат: видит сетку фотографий.
- Пользователь фильтрует по категории / подкатегории. Ожидаемый результат: видны только фото выбранной категории или подкатегории.
- Пользователь вводит поиск по названию или месту съёмки. Ожидаемый результат: видны фото по запросу.
- Пользователь очищает поиск (X). Ожидаемый результат: видны все фото.

### Страница фото
- Пользователь кликает на фото в галерее. Ожидаемый результат: открывается страница фото с метаданными (автор, место, дата, категория) и счётчиками likes и views.
- Пользователь ставит лайк повторно. Ожидаемый результат: счётчик растёт только при первом клике.

### Lightbox и карусель
- Пользователь кликает на фото на странице фото. Ожидаемый результат: открывается lightbox.
- Lightbox закрывается по клику на фон, кнопке X.
- Пользователь переключает фото кнопками Prev / Next. Ожидаемый результат: переключается на следующее или предыдущее фото, счётчик текущего/общего обновляется.
- На первом фото кнопка Prev неактивна. На последнем — кнопка Next неактивна.

### Комментарии (полный цикл)
- Пользователь отправляет комментарий с верной капчей. Ожидаемый результат: комментарий принят, появляется сообщение "на модерации".
- После отправки комментарий не появляется в списке (статус PENDING).
- Пользователь отправляет комментарий с неверной капчей или с ответом быстрее 2 секунд. Ожидаемый результат: ошибка, комментарий не отправлен.
- Админ одобряет комментарий. Ожидаемый результат: комментарий появляется в списке на странице фото.


## Примечания
- **Капча** решается программно через CaptchaHelper (парсинг вопроса и вычисление ответа)
- **Тестовые данные** генерируются динамически: `Фото ${Date.now()}`, `Автор ${Date.now()}`
- **Очистка** после тестов: удаляются все созданные категории, фото, комментарии
