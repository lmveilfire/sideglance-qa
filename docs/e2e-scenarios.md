# E2E Automation Scenarios
> Все сценарии автоматизированы с помощью Playwright. 
> Тесты независимы: каждый создаёт свои данные и удаляет после себя. 

## Администратор

### Аутентификация
- Админ логинится с корректными данными. Ожидаемый результат: редирект на админ-панель.
- Админ вводит неверный пароль. Ожидаемый результат: ошибка, остаётся на /login.

### Управление фото
- Админ загружает фото с файлом, title, author, category, subcategory. Ожидаемый результат: фото появляется в галерее в установленной категории и подкатегории.
- Админ удаляет фото. Ожидаемый результат: фото исчезает из галереи.

### Управление категориями
- Админ создаёт категорию и подкатегорию. Ожидаемый результат: категория и подкатегория появляются в сайдбаре.
- Админ отменяет создание новой категории и подкатегории. Ожидаемый результат: поля ввода очищаются, новые элементы не добавляются в списки.
- Админ удаляет пустую категорию. Ожидаемый результат: категория исчезает из сайдбара.
- Админ удаляет категорию с фото. Ожидаемый результат: категория не удаляется, фото остаются. 

### Управление комментариями (полный цикл)
- Админ открывает список PENDING комментариев. Ожидаемый результат: видит только комментарии на модерации. 
- Админ одобряет комментарий. Ожидаемый результат: комментарий отображается в галерее.
- Админ фильтрует комментарии по статусу. Ожидаемый результат: видны только комментарии выбранного статуса.
- Админ применяет фильтр по одобренным комментариям. Ожидаемый результат: видны только одобренные комментарии.
- Админ отклоняет комментарий. Ожидаемый результат: комментарий остаётся скрытым.
- Админ применяет фильтр по отклоненным комментариям. Ожидаемый результат: видны только отклоненные комментарии.
- Админ удаляет комментарий. Ожидаемый результат: комментарий исчезает из системы.

## Пользователь

### Галерея
- Пользователь открывает главную страницу. Ожидаемый результат: все загруженные фотографии присутствуют на странице.
- Пользователь фильтрует по категории. Ожидаемый результат: видны только фото выбранной категории.
- Пользователь вводит поиск по названию и очищает поисковое поле. Ожидаемый результат: видны только изображения по запросу.

### Страница фото
- Пользователь кликает на фото в галерее. Ожидаемый результат: открывается страница фото с метаданными (имя файла, место, дата) и счётчиками likes и views. 

### Lightbox и карусель
- Пользователь кликает на фото на странице фото. Ожидаемый результат: открывается lightbox. 
- Пользователь переключает фото кнопками Prev / Next. Ожидаемый результат: переключается на следующее или предыдущее фото. На первом фото кнопка Prev неактивна. На последнем — кнопка Next неактивна.


## Примечания
- **Капча** решается программно через CaptchaHelper (парсинг вопроса и вычисление ответа)
- **Тестовые данные** генерируются динамически: `Фото ${Date.now()}`, `Автор ${Date.now()}`
- **Очистка** после тестов: удаляются все созданные категории, фото, комментарии
